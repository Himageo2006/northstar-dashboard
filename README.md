# Northstar Apps Dashboard

Installs, ad revenue, Apple Ads and YouTube numbers for IM NORTHSTAR LABS apps (Benny's Farm, Kingdom Rise, Captain Whiskers, Mud Engineer Pro, MyMindCoach, Ostazzi) and the Happy Kids TV channel.

- Public dashboard: https://himageo2006.github.io/northstar-dashboard/
- claude.ai dashboard: https://claude.ai/artifact/GtFwrbQtJYDnQAcCyLD3r4
- `index.html` — the public page (GitHub Pages), built from `artifact-page.html` by `node tools/build-pages.js`.
- `artifact-page.html` — the page the claude.ai dashboard runs.
- `data/` — the CSV files the dashboard reads, refreshed daily.
- `REFRESH.md` — how the daily refresh collects each number.
